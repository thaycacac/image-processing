# MATLAB labs

Các bài được chia theo chương trong `chapXX/`. Ảnh mẫu dùng chung nằm trong `data/` và được theo dõi trong repo; không cần lấy thư mục `Practice/` hay `anh/` bên ngoài.

Mỗi script tự xác định vị trí của nó bằng `mfilename('fullpath')` rồi đọc ảnh từ `matlab/data`, nên có thể chạy từ MATLAB Current Folder bất kỳ. Mở file `.m` cần chạy và nhấn **Run**.

Một số bài cần MATLAB Image Processing Toolbox. Các bài chỉ dùng thao tác ma trận, số học và FFT không cần toolbox này.

Ảnh mẫu đi kèm: `lenna.tif`, `statue.png`, `mri.jpg`, `shapes23.png`, `cameraman2.tif`, `rice.png`.
